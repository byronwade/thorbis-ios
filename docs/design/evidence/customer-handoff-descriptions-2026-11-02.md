# Customer estimate handoff descriptions

The selected-work review uses the existing issued estimate and protected read-only document reader. Long line and selected-package descriptions are available in a full-height drawer; package descriptions are also available while choosing a package. The reader uses the customer type ramp and its disclosure identifies the estimate and item or package. Prices, selected choices, approval behavior and backend calls are unchanged. This is not a customer catalog or add-on cart: Linear BYR-1580 and BYR-1598 identify the missing server-owned offers, quote, acceptance and billing contract.

The reader is bound to the handoff's current job scope, session and immutable issued revision. The handoff observes request-generation and session-authority changes. Existing reader access checks continue to close a drawer when its authority changes.

Two initial synthetic UI cases failed at the expected missing disclosure on the unmodified review (`/private/tmp/thorbis-handoff-reader-red.log`). The signed iPhone simulator run passed 47 focused handoff, estimate review and presentation unit tests and six UI tests (`/private/tmp/thorbis-handoff-reader-green.log`; xcresult `Test-Thorbis-2026.11.02_21-53-46--0500.xcresult`). UI checks covered a long issued line, selected package, different descriptions on same-title estimates, largest Dynamic Type, a session ending while the reader was open, and the existing estimate document-book reader. No live customer, signature or payment action was made. An invoice-specific reader UI regression and physical-device testing were not included in this run.
