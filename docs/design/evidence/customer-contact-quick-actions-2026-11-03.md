# Customer contact quick actions

On Customer Overview, contact rows now show a shared initials mark and direct call/text circles when the existing phone normalization produces a dialable number. The contact-specific overflow retains Call, Text, Email, Save to Contacts, Edit, Make primary and Remove when each was available before. The existing mutation disable state applies to the shortcuts and menu. At accessibility text sizes the actions stack below the contact. This changes presentation only; it does not change customer data, capability checks, consent or the existing system handoffs.

Reference: Paper “Thorbis — Schedule Redesign”, Thorbis Mobile, “48 · Customer detail” (VQA-0). Adapted the contact initials and direct phone actions to the existing shared SwiftUI tokens and circles; retained the existing overflow to keep all actions reachable.

The new normal-size UI test first failed because the direct call action was absent (`/private/tmp/thorbis-contact-row-red.log`). The first implementation run passed the largest-text test but failed its normal-size Edit assertion because the row was under the pinned footer and the Email assertion could match the page-level button (`/private/tmp/thorbis-contact-row-green.log`). After correcting test navigation and asserting menu-specific actions, two UI tests and nine What’s New tests passed (`/private/tmp/thorbis-contact-row-final.log`, `/private/tmp/thorbis-owner-ui-derived/Logs/Test/Test-Thorbis-2026.11.03_11-24-50--0500.xcresult`). Source hashes are recorded in `/private/tmp/thorbis-contact-row-final-manifest.txt`.

Existing permissive phone normalization remains unchanged. This is an isolated candidate and is not yet a TestFlight build.
