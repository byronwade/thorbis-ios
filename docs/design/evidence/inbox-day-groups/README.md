# Inbox date grouping candidate

The staff notice feed has no event type. The canonical communications query at Thorbis-TanStack commit `3dfd7d20c50102e8b6da059d60bae03d2e9458e3`, `domains/communications/src/job-notices.ts`, constructs `id`, `jobId`, `title`, `meta`, `at` (notice `createdAt`) and `read`; it does not expose a type. This change does not infer one from message text. It adapts the existing Paper Schedule grouped-list grammar to the actual notice feed, which is not the same feature as Paper's channel-based Messages screen.

Consecutive notices are grouped by actual local calendar date in existing order. Repeated days do not get duplicate headings; missing/invalid dates remain in place under Date unavailable and malformed raw values are not displayed. The underlying notice becomes optional for a missing/null timestamp, preserving the row. Unread state, filters, exact job route, loading, error, pagination and permission logic are unchanged. Explicit year-qualified dates avoid stale relative headings at midnight. Formatting uses SwiftUI calendar, locale and time-zone environment; a live system time-zone change was not tested.

`/private/tmp/inbox-day-red.xcresult` failed expected date-header assertions against a placeholder. `/private/tmp/inbox-date-review-red.xcresult` reproduced relative labels where absolute dates were required. `/private/tmp/inbox-date-review-green.xcresult` passed 4 date/decode unit tests, 9 What's New tests and 2 inbox UI tests on the narrow iPhone SE simulator, including invalid/missing timestamp, DST boundary, unread filter and opening the job. `dark-preview.png` is the corresponding synthetic-data screenshot. This does not establish live-data behavior, pagination across day boundaries, VoiceOver/Voice Control, RTL, iPad, physical-device operation or high-volume performance. A test-only `--paper-preview-inbox-day-groups` flag and sample literals must be excluded from any archive.

This candidate has not been archived or uploaded. It needs a fresh independent review of the final absolute-date diff.
