# Job estimate cards

Paper's Thorbis Mobile “Job details (estimates tab)” artboard places each job estimate on a distinct card with its title, amount, status and a short next-step description. This adapts that structure to the existing native record room and its current theme. Each current estimate still opens its same job-scoped detail and uses the existing freshness guard. The job-level customer handoff, creation action, unknown approved amounts, complete options and partial-load recovery are retained. Draft means “Not sent yet”; sent means “Awaiting approval,” without claiming a delivery happened. Unavailable records remain visibly unavailable and cannot open as verified documents.

The baseline UI test failed at the missing sent-status explanation (`/private/tmp/thorbis-job-estimates-scan-red.log`). An initial implementation used lazy rows; its largest-text run failed the existing requirement that both documents exist in the accessibility hierarchy, so the final source restores the previous eager behavior. That same run exposed a new test using the customer-view scroll helper on a job screen; it was corrected to use the actual accessible section chooser and job scroll view (`/private/tmp/thorbis-job-estimates-scan-large.log`).

The final frozen source diff SHA-256 was `0763e8e769123159d2520858919d04c3b8c1d589496de5b97d29ada86915608f`. Two signed iPhone simulator largest-text checks passed on that exact source (`/private/tmp/thorbis-job-estimates-scan-large2.log`, xcresult `Test-Thorbis-2026.11.03_00-54-13--0500.xcresult`), including opening the second document, returning to the customer action and the existing protected-handoff readability case. Five signed normal-size UI checks and nine What's New checks passed on the same source (`/private/tmp/thorbis-job-estimates-scan-final.log`, xcresult `Test-Thorbis-2026.11.03_00-58-04--0500.xcresult`). These cover both cards, other-job exclusion, customer handoff scope, partial/unavailable records, approved/declined states, unknown accepted totals and two complete options.
