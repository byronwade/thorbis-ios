# Customer location label readability — 3 November 2026

Status: staged; not released. Base: build 155 record `7ed3470`.

The customer overview can contain several service and billing locations. The existing label truncated after two lines (three at accessibility sizes), potentially hiding which site a technician should open. Paper Thorbis Mobile customer detail artboard `VQA-0` keeps property and contact information in context; this change retains the current location row, complete address, notes, hazard information, map link and edit/remove actions. It lets the location label wrap fully, and stacks its Service/Billing word below it at accessibility sizes. No data, authorization, offline or navigation behavior is changed.

The focused baseline `/tmp/thorbis-customer-location-layout-red.log` failed for the intended reason: at the largest iPhone text size the long label measured 160 points, below the 220-point test minimum. Simulator verification of the revised layout and screenshots are pending. The site-note-reader experiment is separate and held; it is not part of this change.
