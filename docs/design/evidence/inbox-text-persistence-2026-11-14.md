# Inbox text draft persistence — 14 November 2026

This candidate preserves unsaved composing text in memory when local writes fail, reports that the text is not saved, and offers a copy action. It freezes further writes after an uncertain atomic-write result. Text and canned-reply commits publish their new state only after a successful write; an unsuccessful archive or bin does not close the conversation. Existing blocked text conversations can reopen for recovery; a new unavailable conversation shows an in-app alert rather than silently opening Messages. Call and email threads show a persistent storage warning. Restarting does not preserve unsaved in-memory words: copy them first. This remains device-local draft behavior; no text is transmitted.
