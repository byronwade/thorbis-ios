# Price book reachability at large text

At accessibility text sizes, the price book keeps its search and Done controls available while the title and destination scroll with the results. Item text still uses the user's Dynamic Type size and is not truncated. A separate 44-point add control at the top of each result exposes the complete item name, unit and price through its accessibility label, plus the draft quantity as its value. The item text also remains tappable. Standard-size rows retain their previous layout.

On the unchanged baseline, the focused UI regression failed because the add button's accessibility frame was 380 points tall (`/private/tmp/thorbis-catalog-large-text-red-retry.log`). The initial responsive-row attempt kept the control compact but still failed to reach it; its recording showed a narrow results viewport and swipe gestures starting in the keyboard (`/private/tmp/thorbis-catalog-large-text-green2.log`). An earlier red attempt was interrupted when the test simulator was shut down and did not reach the assertion (`/private/tmp/thorbis-catalog-large-text-red.log`).

The final signed iPhone simulator run passed three selected UI tests (`/private/tmp/thorbis-catalog-large-text-green3.log`, xcresult `Test-Thorbis-2026.11.02_23-22-52--0500.xcresult`). At accessibility XXXL, a long synthetic title, price and full accessibility label were checked; the test scrolled within the visible viewport and added the item twice with the keyboard open. Other cases checked a normal-size text-area tap, distinct invoice lines and search across catalog pages. The captured screenshot is `/private/tmp/catalog-large-green3-attachments/36F38735-5ED4-4588-9FDE-C47E87EF0462.png`: the plus control is visible above Done, and the long item text continues below the viewport. The search field scrolls horizontally to its caret at this text size.

Actual VoiceOver interaction, full long-description scrolling, floating/split keyboards, iPad and a physical device were not separately tested. No live customer or financial data was changed.
