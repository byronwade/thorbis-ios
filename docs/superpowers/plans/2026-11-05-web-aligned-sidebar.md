# Web-aligned native navigation

Bring the existing phone drawer and iPad sidebar closer to Thorbis web's navigation vocabulary while keeping each native destination reachable directly. Web's personal tier is followed by Work, Customers, Money, Reports and Operations. Native-only Attention, Rules and Drafts remain available under Other; phone-local Fleet, Equipment, Agreements and Team additions retain the explicit On this phone section. Do not add routes for web features the native app does not implement.

Existing capability checks, per-phone or company pins, hidden choices, per-section ordering, startup selection, recents, creates and navigation paths are unchanged. The same section builder powers both phone and iPad. Tests must cover role-specific reachability, ordering within a group, hidden choices, explicit pins, local records and the shared rendered sidebar; capture phone and iPad screenshots and inspect large text before release.

This deliberately updates the earlier Work/Money/Shop heading direction in the golden rules in response to the owner's newer instruction to align with the web. It changes hierarchy and naming, not domain authority or customer-mode presentation.
